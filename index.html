Project Overview

The Used Car Price Predictions project aims to help key stakeholders when buying or selling used cars. This includes but is not limited to used car buyers, private sellers, dealerships, and online car marketplaces. Using descriptive analytics and predictive modeling, we intend to describe the most important factors in price change and predict the price of used cars based on those factors.

The project involves collecting and preparing a used-car dataset, performing exploratory data analysis, engineering relevant features, using analytics modeling, and developing a dashboard that demonstrates how predictive analytics can assist users in estimating used vehicle prices.
